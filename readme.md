# Scribble 🎨

Scribble is a real-time collaborative whiteboard application that allows multiple users to draw, create, and interact on a shared canvas. Users can collaborate in the same room, sketch ideas, draw shapes, add text, and make changes that are synchronized in real time.

## ✨ Features

- **Real-time Collaboration** – Multiple users can work together on a shared canvas.
- **Drawing Tools** – Draw rectangles, circles, ellipses, lines, and freehand sketches.
- **Text Support** – Add text directly to the canvas.
- **Shape Manipulation** – Select, move, and erase shapes.
- **Undo & Redo** – Revert or restore previous drawing actions.
- **Room-based Collaboration** – Join shared rooms and collaborate with others.

## 🛠️ Tech Stack

- React
- TypeScript
- HTML Canvas API
- Socket.IO
- Rough.js

## 🚀 Getting Started

Clone the repository:

```bash
git clone git@github.com:Satyam00915/Scribble.git
cd Scribble
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
